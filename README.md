# 신작이 늘면, 장르도 다양해질까?

네이버웹툰 신규 연재 규모와 장르 다양성을 분석하는 **16:9 HTML 슬라이드 12장**입니다.

입문자를 위한 흐름: 연구 질문 → 데이터 → 발견 → 검증 → 결론. 한 장에 하나의 메시지를 전달하며, 수식·구성 분해·표본 보정 계산은 기존 분석 보고서에 보존했습니다.

본문 11장과 결론 뒤 부록 1장입니다. 2장은 실제 관측된 2015년·2022년 구성으로 질문을 던지고, 8장은 유효 장르 수를 설명한 다음 시간 그래프를 보여줍니다. 모든 장의 하단에 ‘18세 이용가를 제외한 네이버웹툰 관측 작품’을 표시합니다.

회차 수는 본문의 장르 분석과 분리해 12장 부록에 배치했습니다. 회차 확인 3,976작품 중 2,976작품(74.8%)이 수집 시점 100회 이하이며, 중앙값은 63회입니다. `data/research/episode_analysis_note.md`에 분모·검증·해석 한계를 기록했습니다. 기존 비교 조건은 데이터 페이지에 통합했습니다.

Published: https://mschoooo.github.io/naver-webtoon-genre-atlas/

## 실행과 조작

이 폴더에서 `python -m http.server 8000`을 실행하거나 index.html을 브라우저로 엽니다.

- 방향키 / Page Up·Down: 이동. Home / End: 처음 / 마지막.
- O: 목차. F: 전체 화면. R 또는 다시 보기: 현재 장의 숫자·그래프 효과 재생. 좌우 터치 스와이프 지원.
- 브라우저 인쇄: 16:9 페이지. 동작 줄이기 OS 설정 지원.

## 자료와 그래프

- 원본: data/naver_webtoon_raw.csv, 4,225작품.
- 공식 이용등급 RATE_18 249편을 제외한 연구 대상은 3,976편입니다. 수집 후 연구 범위를 명시적으로 한정했습니다.
- 연구 대상 내 게시연도 확인 3,975편, 시작연도 결측 1편(0.025%)입니다. 결측 연도는 대치하지 않았습니다.
- data/research/research_scope.csv에 전체 작품의 등급·포함 여부·저장된 근거 파일을, naver_webtoon_research.csv에 원본 열을 보존한 연구 대상 3,976편을 제공합니다.
- 기존 연도별 분석과 ID 집합이 같으며, 연도별 22행·기간별 5행의 H·HHI·로맨스 비중을 독립 재계산했습니다.
- 18세 이용가까지 포함했던 250편의 결측 민감도 분석은 현재 보고서와 본문에서 제외했습니다. 이전 범위의 자료는 로컬 분석 폴더의 archive_all_ratings/에 보존합니다.
- 주 관계 분석: n≥30인 완전 연도 2008–2025년, 18개 연도.
- 2026년은 부분 연도로 연간 관계 분석에서 제외했습니다.
- data/research/의 CSV는 원본에서 계산한 분석 집계표입니다.
- clarity_deck.js가 data/research.js 및 data/stats.js를 읽어 SVG 그래프를 그립니다.
- data/research/analysis_report.html에 전체 분석 방법·결과·한계를 기록했습니다.
- 애니메이션: 로컬 포함 anime.js 3.2.2(MIT). 숫자 세기, 비교 막대, 비율 칸과 추이 선을 단계적으로 표시합니다. 인쇄와 동작 줄이기 설정에서는 최종 값으로 표시합니다.
- Google Fonts Noto Sans KR은 시스템 글꼴 대체 경로가 있습니다.

## 이미지

표지(1장)에만 네이버웹툰 공식 썸네일 6개를 사용합니다. 통계 차트에는 래스터 이미지가 없습니다.

신의 탑, 외모지상주의, 여신강림, 마음의소리, 전지적 독자 시점, 유미의 세포들.

작품명·작가·작품 링크·원본 이미지 URL·해시는 assets/artwork_sources.json과 마지막 슬라이드의 출처 창에 기록했습니다. 원작 이미지의 권리는 각 권리자에게 있습니다. 출처 표기는 재사용 라이선스를 의미하지 않습니다. 이미지는 발표용 예시이며 통계의 대표 표본이 아닙니다. 이미지에 텍스트나 통계 수치를 생성·합성하지 않았습니다.

## 해석과 배포

18세 이용가를 제외한 관측 작품의 현재 대표 장르를 첫 회차 게시연도에 연결한 기술적 분석입니다. 연구 대상의 시작연도 결측은 1편이지만, 불완전한 과거 목록과 현재 장르 분류의 한계 때문에 전체 역사적 다양성 감소로 일반화할 수 없습니다. 상관·구성 분해는 인과 추정이 아닙니다.

GitHub Pages는 main 브랜치 루트를 배포합니다. API 키·Google 로그인 세션은 이 저장소에 포함하지 않습니다.
